# Monopay · 桌游银行配色预览

当前默认主题：**A · 奶油与钴蓝**。

## 页面

- `index.html`：默认 A 的单页预览（我的账本）。
- `themes.html`：A–F 六套主题对比。
- `preview.png`：A 的静态预览图。

## 六套主题

| 代号 | 主题 | 定位 |
|---|---|---|
| A | 奶油与钴蓝 | **默认**；暖纸 + 钴蓝，最稳的银行感 |
| B | 燕麦与松绿 | 更自然、更桌游 |
| C | 石墨与橘 | 更活泼、更工具感 |
| D | 雾紫与柠檬 | 最大胆的浅色 |
| E | 海盐与番茄 | 冷白、干净、强对比 |
| F | 咖啡与电光青 | 唯一深色；夜间/大胆 |

主题只换 CSS 变量，不换布局、组件和文案。所有主题仍禁止金币、黄铜、筹码、骰子、扑克和赌场绒布。

## 打开

直接双击 `index.html` 或 `themes.html`，无需构建。
