# Monopay 桌游账房 · UI 设计规范 v2.1

> 默认主题：**A · 奶油与钴蓝 / Cream & Cobalt**  
> 可切换主题：**B 燕麦与松绿 / C 石墨与橘 / D 雾紫与柠檬 / E 海盐与番茄 / F 咖啡与电光青**  
> 术语更正：游戏内机构统一称 **银行**，不再使用“钱庄”；产品名保留“桌游账房”。  
> 适用范围：Web 移动端，390 × 844 为基准；桌面端居中，最大内容宽度 520 px。  
> 旧 v1“深绿金币”原型已废弃视觉，仅保留页面结构参考。

---

## 0. 结论：从“赌桌”退回到“桌游银行的记账台”

上一版的问题不是绿色不好看，而是**符号选错了**：

> 深绿桌布 + 金币 + 黄铜 + “钱庄” + 筹码，会同时指向赌场，而不是桌游银行。

新方向不换汤不换药地改颜色，而是换一套隐喻：

- **桌游银行**：像一盒桌游里的银行配件，不像一张赌桌。
- **纸卡账本**：像银行回单、计分纸、卡牌说明卡，干净、平放、可读。
- **钴蓝**：秩序、清爽、可信，不靠金属金光制造“贵气”。
- **珊瑚红**：只表示支出、余额不足、破产等需要停一下的状态。
- **游戏币 M 是道具**：界面不制造下注、赢钱、兑换真钱的联想。

一句话：

> **像桌游配件，不像赌场；像银行回单，不像财富广告。**

## 1. 旧方向为什么像赌场

| 旧符号 | 联想 | 新做法 |
|---|---|---|
| 深绿桌布 + 暗角 | 赌桌、牌桌 | 暖白纸面 + 极淡点阵，像计分纸 |
| 金币 M、黄铜、金属渐变 | 筹码、赌场金币 | 平面纸卡 + 钴蓝 + 墨蓝字，不用金属 |
| “钱庄” | 旧式钱庄、赌场账房 | 统一称“银行” |
| 筹码头像 / 玩家筹码 | 下注、押注 | 首字圆形头像，不做筹码形状 |
| 金色渐变主按钮 | VIP、下注、赌场会员 | 钴蓝实色主按钮 |
| “夜航蓝 / 酒红沙龙”主题名 | 赌场休息室、夜场 | 改用颜色描述命名，不用场所名 |
| 3D 硬币、金光、翻转动画 | 老虎机/筹码 | 勾选、纸张滑入、金额 count-up |

**不推荐的方向：**

- 深绿 + 金色 + 黑底：无论怎么调，都容易回到赌场。
- 大面积金属质感、皮革、木纹、霓虹：成本高，且和“游戏币”不匹配。
- 古风书法、钱庄票号、印章满屏：不是桌游银行，是年代戏。
- 过度金融化：蓝白渐变、理财收益、K 线、VIP 等级，也会偏离桌游。

## 2. 四条设计原则

### 2.1 银行感来自秩序，不来自金色

- 用清楚的层级、稳定的间距、明确的数字建立信任。
- 不用金色证明“高级”；金色只作为极少量暖色提示，不做主色。
- 银行台是“办理业务的地方”，不是“下注的地方”。

### 2.2 像桌游配件，不像赌桌

- 纸卡、回单、计分纸、卡牌说明卡是主要材质。
- 背景是桌面上的纸，不是赌桌绒布。
- 玩家是“坐在桌上的人”，不是“筹码”。

### 2.3 金额清楚，操作快

- 每屏最大字号给金额；单位 `M` 永远小两级。
- 付款路径：选人 → 输金额 → 选类别 → 确认，不超过 3 次关键点击。
- 余额不足时禁用确认，并直接说“先收款/抵押，再付这一笔”。

### 2.4 一套默认，多套可切换

- 默认主题先定为 **A 奶油与钴蓝**，不再反复改默认。
- B–F 作为设置里的可切换主题；只换配色，不换布局、组件和文案。
- 允许大胆配色，但每套仍遵守“纸卡 + 墨字 + 一个主色 + 语义色”的结构，不用赌场符号。

## 3. 视觉系统

### 3.1 材质与语义色

| 角色 | 表现 |
|---|---|
| **纸卡 Paper** | 暖白/纯白卡片、轻微纸纹、1 px 边框、软阴影；像桌游里的卡牌和计分纸。 |
| **墨 Ink** | 深蓝黑，不用纯黑；细线、清楚的字重，像打印出来的银行回单。 |
| **钴蓝 Cobalt** | 主操作、银行标签、选中态；饱和但不荧光，一屏只做一次强调。 |
| **珊瑚 Coral** | 支出、错误、破产；只做小面积状态色，不做大面积背景。 |
| **青绿 Teal** | 收入、到账、同步状态；和钴蓝区分，不抢主操作。 |

### 3.2 色彩 token

| Token | 色值 | 用途 |
|---|---|---|
| `--paper-0` | `#FFFFFF` | 卡片、抽屉最高亮面 |
| `--paper-1` | `#FAF6EE` | 页面主背景（奶油纸） |
| `--paper-2` | `#F2EBDD` | 次级表面、输入框 |
| `--ink-900` | `#1A2433` | 主文字、金额 |
| `--ink-600` | `#5A6675` | 次级文字 |
| `--line` | `#E6DED0` | 边框、分隔线 |
| `--bank-700` | `#2563EB` | 主按钮、银行标签、选中态 |
| `--bank-500` | `#3B82F6` | 银行强调、链接 |
| `--bank-100` | `#DBEAFE` | 银行浅底、提示条 |
| `--income` | `#147A62` | 收入、正向金额 |
| `--expense` | `#C94C36` | 支出、余额不足、破产 |

**用色规则：**

- 主色只用 `--bank-700`，一屏最多一个主按钮。
- 收入用 `--income`，支出用 `--expense`；同时带 `+ / −` 符号，不只靠颜色。
- 纸面正文用 `--ink-900`，辅助信息用 `--ink-600`；不用纯黑/纯白。
- 金色、黄铜、金属渐变全部退出主界面；不再保留沙色作为装饰。
- 不用深绿大面积背景、暗角、绒布纹理、筹码图案。

### 3.2.1 主题库

默认 A；B–F 在 `设置 → 外观 → 主题` 切换。所有主题共享同一布局、组件和文案，只替换颜色 token。

| 代号 | 主题 | 底色 / 纸卡 | 主色 | 支出 | 收入 | 适用 |
|---|---|---|---|---|---|---|
| A | **奶油与钴蓝（默认）** | `#FAF6EE` / `#FFFFFF` | `#2563EB` | `#C94C36` | `#147A62` | 最稳的银行感；默认 |
| B | 燕麦与松绿 | `#F4F0E6` / `#FFFCF5` | `#2F6B4F` | `#B85F3F` | `#2F7D5B` | 更自然、更桌游 |
| C | 石墨与橘 | `#F5F5F4` / `#FFFFFF` | `#EA580C` | `#B91C1C` | `#15803D` | 更活泼、更工具感 |
| D | 雾紫与柠檬 | `#F3EFFF` / `#FFFFFF` | `#6D4AFF` | `#B45309` | `#147A62` | 最大胆的浅色 |
| E | 海盐与番茄 | `#F4F7FA` / `#FFFFFF` | `#1D4ED8` | `#D92D3F` | `#0F766E` | 冷白、干净、强对比 |
| F | 咖啡与电光青 | `#191614` / `#26211D` | `#B8F24A` | `#FF7A59` | `#6FE0B0` | 唯一深色；夜间/大胆 |

**切换规则：**

- 主题只挂 `data-theme` 到应用根节点，组件只读 CSS 变量。
- 深色主题 F 的 `--ink` 翻转为浅色，`--paper-0` 翻转为深色卡片；按钮文字用 `--on-primary` 或卡片底色。
- 主题不影响语义：主操作永远是主色，收入永远是青绿，支出永远是珊瑚。
- 主题选择存 localStorage；默认 `cobalt`，非法值回退 `cobalt`。
- 不做“按房间/按玩家”不同主题，避免同局看到的颜色不一致。

### 3.3 字体

| 角色 | 字体 | 用法 |
|---|---|---|
| UI | `PingFang SC / Noto Sans SC / Microsoft YaHei / system-ui` | 正文、按钮、标签、表单；清楚、现代。 |
| Amount | `Bahnschrift / DIN Alternate / SF Pro Display / Helvetica Neue` | 所有金额；`font-variant-numeric: tabular-nums`。 |
| 标题 | 同 UI 字体，600–700 字重 | 页面标题 20–28 px；不使用书法/复古衬线。 |

**字号：**

| 层级 | 字号/行高 | 用途 |
|---|---|---|
| Amount XL | 44–52 / 1.0 | 我的余额、付款金额 |
| Amount L | 28–34 / 1.0 | 净资产、银行统计 |
| Title | 20–28 / 1.2 | 页面标题、抽屉标题 |
| Body | 14–15 / 1.65 | 正文、说明 |
| Caption | 11–12 / 1.5 | 时间、类别、辅助 |
| Micro | 10–11 / 1.2 | 标签、印章、角标 |

- 不加载 Web Font；中文系统字体足够。
- 金额是主角，标题不抢金额；金额下面必须有一句人话。
- 不做全大写英文装饰墙；少量英文标签只做气氛。

### 3.4 布局与表面

- 390 × 844 基准；页面左右 20 px；卡片间距 12 px；8 pt 网格。
- 触控目标 ≥ 44 px；底部主按钮 52 px；底部导航 60–64 px + 安全区。
- 单列；桌面端居中 480–520 px，不做仪表盘。
- 卡片圆角 16–20；抽屉圆角 24；输入/键盘 10–12；Chips 999。
- 卡片：`#FFFDF8` 底、1 px `--line` 边框、软阴影；**不用大面积渐变**。
- 背景：暖白纸面 + 极淡点阵（16 px 间距，透明度 4–6%），像计分纸/方格纸，不像赌桌绒布。
- 手机框体：中性墨灰，不用绿金外壳；状态栏深色图标。
- 深色底只用于“银行台”一小块统计条或选中态，不做整屏赌桌。

### 3.5 图标与插画

- 图标统一 Lucide，线宽 1.8，尺寸 20/24。
- 用：`bank`（银行）、`receipt`（流水）、`users`（玩家）、`arrows`（收付）、`scale`（对账）、`check`（成功）。
- 不用：金币、筹码、骰子、扑克、老虎机、钱袋、金属钱箱。
- 空状态用单色线稿：空账本、空座位、回单；不画赌场元素。

### 3.6 品牌图标（待重做）

- 现有 icon 的“深绿底 + 金币 M”也需要退出默认：它和赌场金币的联想太强。
- 新方向：圆角方牌 + 奶油纸卡/回单 + 墨蓝色 `M` 字标；或 `M` 字标 + 钴蓝圆点。
- 不用金币外圈、金属高光、赌场绿绒、筹码叠图。
- 图标先出 2–3 个黑白/单色草图，再上色；确认后再替换 `docs/design/brand/icon-*`。

## 4. 核心组件

### 4.1 余额卡

- 暖白纸卡，不是深色金属卡。
- 顶部：`可用余额` + 小号 `BANK` 标签（钴蓝）。
- 中部：金额 44–52 px，`M` 小两级。
- 底部：`本局游戏币 · 不兑换现金`，右侧 `明细 →`。
- 不使用金币、筹码、金属圆章。

### 4.2 玩家行

- 高 44–48 px；首字圆形头像（低饱和色），不是筹码。
- 左：头像 + 昵称 + `房主 / 我 / 破产` 标签。
- 右：余额，等宽数字。
- 自己那行用浅钴蓝底 + 左侧 2 px 钴蓝线，不整行反色。

### 4.3 账本行

- 高 40–44 px；左侧 28 px 回单/箭头图标。
- 主文案：`租金 · 付给小美`；辅助：`20:14 · 我`。
- 右侧：收入 `+200 M` 青绿；支出 `−200 M` 珊瑚红。
- 退款/冲正保留原行，追加反向记录，用文字标签标注；不删除原流水。
- 新交易只做一次 4 px 上移 + 淡入，不做整列表重排动画。

### 4.4 按钮

| 类型 | 样式 | 用途 |
|---|---|---|
| Primary | `--bank-700` 实色 + 白字 | 付款、开桌、确认结算 |
| Secondary | 白底 + `--line` 描边 + 墨字 | 返回、取消、查看流水 |
| Quiet | 纯文字 + 箭头 | 明细、全部、切换 |
| Danger | 珊瑚描边/文字 | 解散、冲正、破产标记 |

- 高 52；圆角 14–16；按下 `scale(.98)` 120 ms。
- Disabled：透明度 40%，旁边说明原因（余额不足/未选收款人）。
- 不使用金色渐变、发光、金属描边。

### 4.5 Chips 与状态

- Chips 高 28–32；默认白底墨字；选中钴蓝底白字。
- 类别不做彩虹色；颜色只表达状态。
- 状态用胶囊/文字标签：`对局中`、`结算中`、`已退款`、`已冲正`、`破产`。
- 不用火漆印章、金属徽章、筹码叠图。

### 4.6 底部抽屉与数字键盘

- 白纸抽屉，顶部圆角 24；遮罩 `rgba(30,43,49,.42)` + 2 px 模糊。
- 标题 20；副标题 12；右上关闭 44 × 44。
- 数字键盘 3 列 × 4 行，键高 48–52；退格右下；确认只在底部出现一次。
- 主按钮钴蓝；按钮上方显示“支付后余额”或“余额不足”。

### 4.7 银行台

- 标题用 `银行台`，不用 `钱庄账台`。
- 统计：`本局发行 / 已回收 / 净投放`，用白卡 + 钴蓝数字，不用黑金统计牌。
- 动作：`发工资`、`银行付款`、`银行收款`、`冲正 / 矫正`。
- 明确写：`银行余额无限 · 不参与排名`。
- 工资默认 200 M，单人，直接入账，不二次确认。

## 5. 动效

| 场景 | 时长 | 说明 |
|---|---|---|
| 页面进入 | 200 ms | 8 px 上移 + 淡入 |
| 抽屉进入 | 260–280 ms | 底部滑入，弹簧 |
| 按钮按下 | 120 ms | `scale(.98)` |
| 金额 count-up | 300 ms | 只用于到账/成功 |
| 成功勾选 | 320 ms | 一次，不循环 |
| 新流水 | 180 ms | 4 px 上移 + 淡入 |

- 只动 `transform` / `opacity`；不动 `height` / `box-shadow` / `filter`。
- 不做金币翻转、筹码飞入、老虎机滚动、金光闪烁。
- 中端 Android 目标 60 fps；`prefers-reduced-motion` 时全部直接切换。
- 音效只给收款人；银行收款静音；退款给原付款人响。

## 6. 页面内容

### 6.1 首页｜开一桌

- 品牌：`MONOPAY / 桌游账房`。
- 标题：`这桌的钱，银行来记。`
- 副标题：`只接管钱，不接管棋盘。`
- 主按钮：`开一桌`；次按钮：`加入房间`。
- 最近房间：`上次的桌 · 672418 · 对局中`，`继续 →`。
- 底部：`仅使用游戏币 M，不可充值、提现或兑换现金。`

### 6.2 创建房间｜这桌的银行规则

- 房间身份（创建后不可改）：
  - `只做银行`：`我不入局，只负责发钱、收款、对账。`
  - `银行 + 玩家`：`我也在桌上，可切换银行/玩家操作台。`
- 初始资金 `2,000 M`；最大玩家 2–6；工资 `200 M`；大额阈值 `1,000 M`；音效默认开。
- 主按钮：`开桌`。
- 提示：`开局后，初始资金只发一次。`

### 6.3 大厅｜等大家入座

- 房号 `672 418` + 复制/二维码。
- 玩家座位：头像 + 昵称 + `房主 / 已入座`。
- 空位：`还差 1 人`。
- 主按钮：`人齐了，开桌`；人数不足时禁用。

### 6.4 我的账本

- 顶栏：房号 + `对局中` + 当前身份。
- 余额卡：`可用余额` + `2,450 M` + `本局游戏币`。
- 操作：`付款`（主）、`流水`、`银行台`（房主/双身份）。
- 桌上的人：玩家余额；自己高亮；破产标记。
- 最近流水 3–5 条。
- 底部导航：`账本 / 流水 / 对账 / 设置`。
- 余额不足：`余额不足。先收款、抵押或变卖，再付这一笔。`

### 6.5 银行台

- 标题 `银行台` + `房主` + `切到玩家`。
- 统计：发行、回收、净投放；脚注 `银行余额无限，不参与排名`。
- 动作：`发工资`、`银行付款`、`银行收款`、`冲正 / 矫正`。
- 玩家列表：余额 + `发 200`。
- 文案：`工资默认 200 M，只能发给一位玩家，发出后立即到账。`
- 文案：`银行付款 = 发行；银行收款 = 回收。`

### 6.6 付款

- 标题 `付款`；副标题 `从「我的余额」支出`。
- `付给`：玩家/银行横向选择。
- 金额大号 + `M`；快捷 50/100/200/500；数字键盘。
- 类别：`租金 / 过路费 / 机会卡 / 罚款 / 其他`。
- 备注可选。
- 主按钮：`确认支付 200 M`；下方 `支付后余额 2,250 M · 即时到账`。
- 大额：`这笔 1,200 M 超过大额阈值，请再确认一次。`
- 余额不足：`余额不足，还差 150 M。先收款/抵押，再付这一笔。`

### 6.7 流水｜账本

- 标题 `账本`；筛选 `全部 / 我付出 / 我收到 / 银行`。
- 日期分隔 + 账本行 + 详情。
- 退款仅收款方可见，全额原路退回，不需付款方确认。
- 冲正仅房主可见，必须填原因；原流水保留。
- 空状态：`还没有流水。第一笔交易会记在这里。`

### 6.8 结算｜对账

- 标题 `对账` + `结算中` 标签。
- 标题句：`把账对平，再收桌。`
- 说明：`资产估值和负债未填时按 0 计。`
- 排名：净资产从高到低；`我` 标签；破产玩家保留排名 + `破产` 标签。
- 明细：`现金 + 资产估值 − 负债 = 净资产`。
- 底部：`返回对局` + `确认结算`；`确认后只读，仍可查看流水。`

### 6.9 设置 / 帮助

- 分组：`本局`（音效、操作台切换、规则）、`房间`（房号、分享、离开/解散）。
- 外观/主题本轮不做；等默认方向确认后再评估。
- 危险操作单独分组，珊瑚文字，二次确认。

## 7. 文案语气

- 短、准、清楚；不古风、不卖萌、不感叹号。
- 机构统一叫 **银行**；不用“钱庄、庄家、下注、筹码、赌桌、金币”。
- 金额统一 `2,000 M`；不用“元/块/钱包/充值/提现”。
- 用“余额、入账、出账、流水、对账、发行、回收”。

| 通用写法 | Monopay 写法 |
|---|---|
| 暂无数据 | 还没有流水。第一笔交易会记在这里。 |
| 支付成功 | 已付 200 M 给小美。 |
| 操作失败 | 余额不足。先收款/抵押，再付这一笔。 |
| 请确认 | 确认支付 200 M |
| 结算完成 | 账已对平，本局结束。 |
| 提示 | 这笔 1,200 M 超过大额阈值，再确认一次。 |

## 8. 落地映射

- 用 CSS 变量 / Tailwind theme 管理 `paper / ink / primary / income / expense / line`，组件里不写死颜色。
- 默认主题 A `cobalt`；B–F 通过根节点 `data-theme` 切换，只换变量，不重挂组件。
- 主题选择存 localStorage（`monopay-theme`）；默认 `cobalt`，非法值回退 `cobalt`。
- 深色主题 F 需要同时翻转 `--ink` / `--paper-0` / `--line`，不能只换主色。
- Vant 只用行为组件（NumberKeyboard、Popup、Field、Dialog），皮肤用自定义 token 覆盖。
- 旧 `docs/design/prototype/index.html` 是 v1 深绿金币方向，仅保留布局/交互结构参考，不再作为视觉验收依据。
- 新配色预览：`docs/design/preview-v2/index.html`（默认 A）、`docs/design/preview-v2/themes.html`（A–F 六套）。
