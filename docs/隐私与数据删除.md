# 隐私与数据删除说明

> Monopay 桌游账房只记录一局桌游的游戏币流水，不接入真钱，不登记真实资产。

---

## 1. 我们记录什么

| 数据 | 用途 |
|---|---|
| 房间号、房主身份、初始资金、房间状态 | 让同一桌玩家进入同一局 |
| 昵称、头像标识（emoji/文字） | 在余额和流水中区分玩家 |
| 游戏币余额、流水、退款/冲正、资产估值/负债 | 账本和对账 |
| 设备随机生成的房间凭证 hash | 断线重连；原始 token 只存在浏览器 |
| 创建/更新时间、房间事件 | 24 小时无活动自动解散、7 天清理 |
| 访问日志 | 排障和安全；Authorization 已脱敏 |

**不记录**：真实姓名、手机号、支付账号、身份证、真实房产、银行卡、充值/提现记录。

---

## 2. 浏览器本地存储

- `monopay.room.<code>.hostToken` / `monopay.room.<code>.playerToken`：本机在该房间的凭证；换设备不会自动同步。
- `monopay.lastRoom` / `monopay.lastRoomUrl`：上次房间入口。
- `monopay-theme`：主题偏好。
- `monopay-muted`：音效开关。
- `monopay.lastAmount`：上次付款金额（仅本机）。

清除浏览器站点数据会丢失本机房间凭证；需要房主重新分享链接/房号，或使用同一浏览器备份。

---

## 3. 保留与删除

- 房间 24 小时无活动：自动标记 `dissolved`，只读。
- `dissolved` 或 `settled` 房间：保留 7 天用于恢复/对账，之后自动物理删除房间及其玩家、流水、资产、结算记录。
- 备份：每日 SQLite 备份默认保留 7 天；备份中可能仍包含已删除房间，到期后随备份清理。
- 房主可随时“解散房间”；解散后立即只读，7 天内可联系运维恢复，超过保留期不可恢复。
- 测试/压测数据不进入生产库。

删除是级联的：删除 `rooms` 行会删除该房间的 `players`、`transactions`、`asset_snapshots`、`settlements`、`room_events`。

---

## 4. 共享与第三方

- 不接入广告、统计 SDK、支付 SDK。
- 页面使用系统字体和本地打包资源；不使用外部字体 CDN。
- 二维码在本机生成，不上传房间链接。
- 生产访问通过现有 Nginx/Traefik 等反向代理终止 HTTPS；app 容器不保存证书。

---

## 5. 安全

- 房间 token 32 字节随机，服务端只存 SHA-256 hash。
- 日志对 Authorization 脱敏。
- 单副本 SQLite；备份文件按敏感数据管理。
- 发现凭证泄露：房主解散房间，换新房间；旧 token 随房间清理失效。

---

## 6. 联系与删除请求

自部署版本由部署者负责运维。删除请求可直接解散房间，或在服务器上按运行手册恢复备份后清理；生产环境建议在页脚/仓库 README 提供运维联系方式。
