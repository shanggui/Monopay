# Monopay · 旧视觉原型（v1，已废弃）

> **注意：当前 `index.html` 是旧“深绿金币”视觉方向，因赌场感过强已废弃。**
> 它只保留页面结构和交互参考，不再作为视觉验收依据。新方向见 [UI 设计规范 v2.0](../docs/UI设计规范.md)：**桌游银行 · 纸卡与薄荷**。

## 旧原型内容

- 我的账本：余额卡、快捷付款、桌上的人、最近流水。
- 付款抽屉：收款人、金额、数字键盘、类别、确认。
- 银行台：发行/回收统计、发工资、银行付款/收款、冲正/矫正。
- 对账页：净资产排名、资产/负债明细、对账说明、确认结算。

旧版交互仍可点：付款金额、收款人、类别；余额不足时禁用确认。

## 当前状态

- **不是**生产前端代码，也**不是**新视觉方向。
- 新原型的下一步：按 `docs/UI设计规范.md` 的“纸卡与薄荷” token 和组件清单重做。
- 旧版的主题切换（墨绿/夜航蓝/酒红沙龙/奶油票据）一并废弃，不再沿用。
